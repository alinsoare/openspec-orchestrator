# Changelog

## 1.0.0

First release: an agent skill for spec-driven development on top of OpenSpec — propose a delta spec, critique it, implement it in units, gate and verify it, archive it into the living spec — routed to a local `openspec/` folder or an external store, with per-tier agents for Claude Code, Cursor, VS Code/Copilot, Codex and OpenCode installed by `tools/install.sh`.
